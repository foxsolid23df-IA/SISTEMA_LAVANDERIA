# Manual: Registro de Nuevos Clientes - Sistema Lavandería

Este manual describe el proceso para gestionar clientes dentro del nuevo sistema de recepción de lavandería.

## 1. Importancia del Cliente

En un sistema de lavandería, a diferencia de una tienda retail, el registro del cliente es **obligatorio**. Sin un cliente asignado, no es posible generar una orden, ya que el sistema necesita saber a quién entregar las prendas una vez listas.

## 2. Cómo buscar un Cliente Existente

1. Diríjase al módulo de **Ventas (Recepción de Lavandería)**.
2. En la parte superior, localice el campo **"CLIENTE (OBLIGATORIO)"**.
3. Escriba el nombre o el teléfono del cliente.
4. Si el cliente ya existe, aparecerá en una lista desplegable. Haga clic en su nombre para seleccionarlo.

## 3. Cómo registrar un Cliente Nuevo

Si al buscar no encuentra al cliente, siga estos pasos:

1. Haga clic en el botón verde con el ícono de persona y un signo "+" (**Registrar Nuevo Cliente**) ubicado a la derecha del buscador.
2. Se abrirá una ventana modal.
3. Ingrese los datos solicitados:
   - **Nombre Completo:** (Obligatorio)
   - **Teléfono:** (Recomendado para notificaciones)
   - **Dirección:** (Opcional, útil para entregas a domicilio)
4. Haga clic en **"Guardar y Seleccionar"**.
5. El sistema guardará al cliente en la base de datos y lo dejará seleccionado automáticamente para la orden actual.

## 4. Modificación de Datos

Por el momento, la modificación rápida de datos se realiza volviendo a seleccionar al cliente. Próximamente se añadirá un editor directo desde la recepción.

---

_Nota: Asegúrese de capturar correctamente el teléfono, ya que el número de orden y las notificaciones se basan en este contacto._
