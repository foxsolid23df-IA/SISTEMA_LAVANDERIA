# 📘 Manual de Usuario: Gestión de Clientes en el Sistema de Lavandería

¡Bienvenido al nuevo sistema de recepción! Este manual te guiará paso a paso en el proceso de **búsqueda, registro y gestión de clientes**.

A diferencia de una tienda regular, en una lavandería **el registro del cliente es obligatorio**. Es fundamental saber a quién le pertenecen las prendas, cómo contactarle cuando estén listas y a dónde entregarlas.

---

## 🔍 1. Cómo buscar un Cliente Existente

Antes de registrar a alguien nuevo, **siempre** debemos verificar si ya existe en el sistema para evitar registros duplicados.

1. Dirígete a la pantalla principal de **Recepción de Lavandería (Nueva Venta o Recepción)**.
2. En la parte superior, localiza el recuadro de búsqueda llamado **"📋 CLIENTE (OBLIGATORIO)"**.
3. Escribe el **nombre completo** o el **número de teléfono** del cliente.
4. Conforme escribas, el sistema buscará coincidencias. Si el cliente ya existe, aparecerá en una lista desplegable justo debajo.
5. **Haz clic** en el nombre del cliente en la lista para seleccionarlo. ¡Listo! Ya puedes proceder a agregar sus servicios y prendas.

> **💡 Tip Rápido:** Buscar por número de teléfono es la forma más rápida, exacta y segura de encontrar a un cliente que ya nos ha visitado.

---

## ➕ 2. Cómo registrar un Cliente Nuevo

Si buscaste al cliente (por nombre y teléfono) y no apareció en la lista, significa que es su primera vez con nosotros. Para registrarlo:

1. Ubica el botón verde con el ícono de una persona y el signo **"+"** (Registrar Nuevo Cliente). Está a la derecha del buscador de clientes.
2. Al hacer clic, se abrirá una ventana emergente (modal) de registro.
3. Llena los datos del cliente con cuidado:
   - 👤 **Nombre Completo:** (Obligatorio) Pide su nombre y al menos un apellido.
   - 📱 **Teléfono / WhatsApp:** (Muy Recomendado) Es vital para enviarle notificaciones de que su ropa está lista o contactarlo por cualquier duda.
   - 📍 **Dirección:** (Opcional) Muy útil si solicitaron o podrían solicitar entrega a domicilio en un futuro.
4. Haz clic en el botón azul **"Guardar y Seleccionar"**.
5. ¡Perfecto! El sistema guardará al cliente de forma segura y lo dejará seleccionado automáticamente para que continúes armando su orden sin interrupciones.

---

## ⚠️ 3. Prevención de Duplicados (Nombres Similares)

El sistema ahora cuenta con una validación inteligente para mantener nuestra base de datos limpia y organizada.

- **Si intentas registrar a un cliente con un nombre o teléfono que ya existe**, el sistema te avisará.
- Te sugerirá que utilices el cliente existente en lugar de crear uno nuevo.
- Si realmente se trata de una persona diferente pero con el mismo nombre (ej. "Juan Pérez"), te recomendamos agregar un distintivo, como su segundo apellido o un detalle (ej. "Juan Pérez (Centro)").

---

## ✏️ 4. Modificación de Datos del Cliente

Si notas que el teléfono o la dirección de un cliente seleccionado tiene un error y necesitas actualizarlo:

1. En la pantalla del perfil del cliente o módulo de clientes, puedes buscarlo y editar su información.
2. _(Próximamente)_ Se habilitará un botón de edición rápida (ícono de lápiz) junto al cliente seleccionado para actualizar sus datos sin salir de la orden actual de manera más directa.

---

### ⭐ Buenas Prácticas y Recomendaciones Finales

- **Verifica siempre el teléfono:** Antes de confirmar la orden, rectifica con el cliente si su número sigue siendo el mismo. Las notificaciones y el seguimiento dependen de este dato.
- **Escribe correctamente (Uso de Mayúsculas):** Registrar "María López" da una imagen mucho más profesional en los tickets o notas que escribir "maria lopez".
- **Atención al Cliente:** Aprovecha el momento del registro para ofrecer un trato amable y personalizado. ¡Es el primer paso para un servicio de calidad!

---
