# 🚀 Guía de Actualización del Sistema - FoxSolid 2026

¡Hola! Para asegurar que siempre tengas la mejor experiencia, funciones nuevas y la mayor seguridad, hemos implementado un **Sistema de Actualización Automática**.

Ahora, mantener tu sistema al día es más fácil que nunca. Aquí te explicamos cómo funciona:

---

### 1. 🔍 Detección Automática

Cada vez que inicias el sistema, este revisará si existe una versión más reciente. No necesitas buscar discos ni descargar archivos manualmente de internet.

### 2. ⚡ Descarga en Segundo Plano

Si hay una actualización disponible, el programa la descargará **mientras tú trabajas**.

- **No se interrumpen tus ventas.**
- **No notarás lentitud en el equipo.**
- Puedes seguir registrando órdenes y cobrando normalmente.

### 3. 🔔 Notificación de Instalación

Una vez que el sistema termine de descargar la mejora, aparecerá una ventana informativa como esta:

> **Actualización Lista**
> Una nueva versión ha sido descargada. El sistema se reiniciará para aplicar los cambios.
> [ Reiniciar Ahora ] [ Más tarde ]

- **Reiniciar Ahora**: Recomendado. El sistema se cerrará, se actualizará en 5 segundos y se volverá a abrir solo.
- **Más tarde**: Si estás atendiendo a un cliente importante, puedes elegir esta opción. El sistema te volverá a preguntar más tarde o se actualizará la próxima vez que lo abras.

### 4. ✅ Verifica tu Versión

¿Quieres saber qué versión tienes? Es muy fácil:

1. Mira en el **Menú Lateral Izquierdo**.
2. Debajo de tu nombre y rol (donde dice Propietario o Operador), verás una pequeña etiqueta que dice: **v1.3.1** (o la versión actual).

---

### ❓ Preguntas Frecuentes

- **¿Se borrarán mis datos o ventas?**
  Absolutamente **NO**. La actualización solo mejora el programa, tus datos están seguros y no se tocan.
- **¿Tarda mucho en instalarse?**
  No. El proceso de reinicio e instalación suele tomar menos de 10 segundos.
- **¿Necesito internet?**
  Sí, se requiere conexión a internet únicamente para detectar y descargar la mejora. Una vez instalada, el sistema sigue funcionando offline como siempre.
