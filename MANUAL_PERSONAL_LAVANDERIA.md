# 🧺 Manual de Operación para el Personal - Lavandería 2026

Bienvenido al sistema de gestión de la lavandería. Este manual contiene los pasos básicos para operar el sistema de forma eficiente.

## 1. Acceso al Sistema

- **PIN Personal**: Cada empleado tiene un código único de 4 a 6 dígitos.
- **Bloqueo**: Si te alejas de la computadora, presiona el botón "Bloquear" en el menú lateral.

## 2. Ventas de Mostrador (POS)

Para realizar una venta de productos (jabones, suavizantes, etc.):

1. Ve a la sección **Ventas**.
2. Escanea el código de barras o busca el producto por nombre.
3. Agrégalo al carrito.
4. Presiona **Cobrar**, selecciona el método de pago y finaliza.

## 3. Gestión de Órdenes (Lavandería)

Este es el corazón del negocio para el servicio de lavado:

1. **Recibir Ropa**: Ve a "Órdenes" -> "Nueva Orden". Registra las prendas y el peso.
2. **Proceso de Lavado**: Cuando la ropa entre a lavadora, cambia el estado a "En Proceso".
3. **Prendas Listas**: Cuando la ropa esté seca y doblada, marca la orden como "Listo". El sistema puede enviar una notificación si está configurado.
4. **Entrega**: Cuando el cliente venga por ella, busca la orden por nombre o ID, registra el pago restante (si hay) y marca como "Entregado".

## 4. Corte de Caja

Dbe hacerse al final de cada turno:

1. Ve a "Corte de Caja" en el menú lateral.
2. Cuenta el dinero físico en el cajón.
3. Ingresa el monto en el sistema.
4. El sistema comparará lo que "debe haber" contra lo que contaste.
5. Imprime el reporte de corte si es necesario.

## 5. Sincronización (Muy Importante)

Si el internet falla, el sistema seguirá funcionando localmente.

- Busca el icono de **Nube** en la esquina inferior izquierda.
- **Verde**: Conectado y sincronizado.
- **Rojo/Gris**: Sin conexión. Las ventas se subirán automáticamente cuando vuelva el internet.
- Puedes forzar la sincronización en el **Panel de Administración** -> **Configuración**.

---

**Soporte Técnico**: En caso de error crítico, contacta al administrador de la tienda.
