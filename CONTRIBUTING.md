# Contribuir al SISTEMA LAVANDERIA

¡Gracias por tu interés en contribuir! Este documento describe las normas para colaborar en el proyecto.

## 🚀 Proceso de Desarrollo

1. **Fork del Repositorio:** Crea tu propia copia.
2. **Crear una Rama:** `git checkout -b feature/mi-nueva-funcionalidad`.
3. **Commit de Cambios:** Usa mensajes claros y profesionales en español o inglés siguiendo los estándares de [Conventional Commits](https://www.conventionalcommits.org/).
4. **Push a la Rama:** `git push origin feature/mi-nueva-funcionalidad`.
5. **Abrir un Pull Request:** Describe detalladamente tus cambios.

## 📝 Estándares de Código

- Sigue las reglas de ESLint configuradas.
- Mantén el código limpio y bien documentado.
- No incluyas secretos ni variables de entorno en tus commits.
- Asegúrate de que las pruebas pasen antes de enviar el PR.

## 🐞 Reportar Bugs

Si encuentras un error, por favor abre un *Issue* en GitHub proporcionando:
- Descripción detallada del bug.
- Pasos para reproducirlo.
- Entorno (SO, Versión de Node, etc.).
- Capturas de pantalla si es posible.
